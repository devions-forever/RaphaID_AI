# RaphaID AI — Work Log 2026-09-26

## UI repair + upgrade pass (Streamlit clinical dashboard)

### Root causes fixed
1. **`theme.py` NameError** — `apply_theme()` crashed with `NameError: name 'background' is not
   defined`. The stylesheet was built with an f-string and the CSS braces after the button section
   were never escaped, so Python parsed `{ background-color: ... }` as an f-string expression.
   Fixed by rebuilding the whole stylesheet as a `string.Template` (`$token` substitution only), so
   CSS braces can never be misread again.
2. **Streamlit strips inline `style` attributes containing `!important`** — verified with a
   controlled probe: a div with `style="display:flex !important"` renders with `style=null`.
   This silently un-fixed the splash overlay (its root had `!important` everywhere) and broke its
   centring. Rule: inline styles must be plain; hard overrides belong in the injected stylesheet.
3. **Markdown 4-space code-block trap** — any injected HTML whose first line is indented by 4+
   spaces renders as literal escaped text. This broke the sidebar brand/telemetry blocks, the
   footer panels, `components/ui.py` cards, the dashboard hero and the workflow stepper.
   Fixed with `app/components/htmlkit.py::render_html()` which collapses markup to one line.
4. **Child selectors defeated by wrappers** — Streamlit wraps `<button>` in
   `div[data-testid="stTooltipHoverTarget"]`, so `.stButton > button` never matched. All button
   CSS is now descendant-based (`[data-testid="stButton"] button`).
5. **White label on teal fill** — Streamlit paints primary-button labels white. Added an app-wide
   `button[kind="primary"] * { color: #08111F }` rule (13.9:1 contrast). Verified computed styles.
6. **`position: sticky` did nothing** — a sticky element can only travel inside its parent's box,
   and `st.markdown` wraps content in a container exactly as tall as itself. Stickiness must be
   applied to the `stElementContainer` wrapper via `:has()`.
7. **Sidebar would not collapse** — a hard-coded `width/min-width: 300px !important` on
   `[data-testid="stSidebar"]` prevented it; now scoped to `[aria-expanded="true"]`.
8. **Stray duplicate chevron** — raising `stSidebarCollapsedControl` z-index made a second
   collapse button appear over the open sidebar. Streamlit relies on the expanded sidebar painting
   over that control; the z-index override was removed.
9. **Latent `KeyError: 'submodules'`** in `navigation.py` — the radio `format_func` closure
   late-bound the loop variable. Replaced with a module-level function + `functools.partial`.
10. **"Reload KB" never re-indexed** — guarded by `"rag_initialized" not in st.session_state`;
    now an explicit `not st.session_state.get("rag_initialized", False)` check.
